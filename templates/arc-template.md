# 架构需求核对与质量保障清单 (Architecture Requirements Checklist, ARC)

> 架构视角：质量保障 (Quality Assurance & Governance)  
> 核心作用：将可用性、安全性、吞吐量等 NFRs 进行指标量化（如 RTO/RPO、P99 延迟）并逐项追踪闭环。

---

## 1. 架构需求质量属性闭环追踪表 (ARC Traceability Matrix)

| 需求编号 | 质量属性类别 | 量化设计指标 (Target Metric) | 极端峰值 / 约束边界 | 落地实现架构方案 | 验证与度量手段 | 闭环状态 (Open/Closed) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **ARC-01** | **高并发吞吐** | 常态处理能力 ≥ 500,000 QPS | 突发峰值 ≥ 2,000,000 QPS | 无阻塞 Reactive Stream + 协程池 + Redis 分片 | 压测工具集群注入基准流量 | CLOSED (已压测达标) |
| **ARC-02** | **超低处理时延** | 核心热链路 P95 < 25ms, P99 < 50ms | 极端场景 P99.9 < 80ms | 内存体素哈希、避免跨网络同步、独占 CPU 绑核 | W3C Trace 链路耗时埋点直方图 | CLOSED (微秒级基准通过) |
| **ARC-03** | **高可用性 (SLA)** | 系统服务可用性 ≥ 99.999% | 年均计划外停机 < 5.26 分钟 | 多可用区 (AZ-1/AZ-2) 同城双活 + 边缘离线自治 | 混沌工程随机终止 30% 节点演练 | CLOSED (双活架构就绪) |
| **ARC-04** | **容灾恢复 RTO** | 核心调度状态切换 RTO < 1秒 | 遥测流恢复 RTO < 3秒 | Patroni 自动主从故障转移 + Anycast 流量自愈 | 模拟单机房断电切流演练 | CLOSED (指标已固化) |
| **ARC-05** | **数据完整性 RPO** | 飞行/业务核心流水严格 RPO = 0 | 审计轨迹数据零丢包 | 双写 Quorum + Raft/WAL 预写日志 | 分布式事务一致性校验探针 | CLOSED (无单点无缓存穿透) |
| **ARC-06** | **传输与访问安全** | 全链路 mTLS 1.3 + 国密验签 | 防重放时间戳窗口 ≤ 500ms | 硬件安全模块 (HSM) / 证书颁发体系 | 自动化渗透测试与抓包脱敏复核 | CLOSED (握手门禁已实施) |
| **ARC-07** | **弹性可扩展性** | 具备水平扩容能力，线性加速比 ≥ 0.85 | 10倍流量可在 3 分钟内自动弹缩 | K8s HPA 依据自定义指标 (QPS/Queue Lag) 弹性伸缩 | 阶梯式递增压测曲线验证 | CLOSED (HPA已配置) |
