## 3. 治理机制与生命周期流转 (Governance Lifecycle)
所有架构决策均遵循 IBM Architecture Thinking 标准生命周期状态机管理：
- **提议 (Proposed)**: 产生于架构探索或 ATAM 效能评估阶段，必须给出量化指标与至少 2~3 个真实可行备选方案。
- **已接受 (Accepted)**: 经过架构评审委员会（ARB）正式立项评审合入，作为后续工程实现与自动化验证必须遵从的不可违背法则。
- **已废弃 (Deprecated)**: 随着业务诉求变更或底层技术基座发生范式迁移而停止遵从。
- **被取代 (Superseded by ADR-XXX)**: 历史决策严禁直接抹除或静默篡改，必须通过新 ADR 声明继承并取代。

## 4. 架构五位一体全要素闭环关联 (Architecture Closure)
- **ARC (量化契约)**: 为 ADR 提供裁决正误的唯一量化裁判尺（如 TCR、TTFT、Token 成本上限、RTO/RPO）。
- **AOD (全局概览)**: 划定 ADR 适用的系统边界、物理分层与高阶控制信息流。
- **CM (组件模型)**: 为 ADR 决议落地具体的逻辑与物理中间件构建物（如 COMP-CTX、COMP-TOOL）。
- **OM (运行模型)**: 为 ADR 决议分配物理部署节点、GPU 算力集群与安全沙箱隔离区。
- **AD/ADR (决策法典)**: 沉淀所有重大技术抉择的根本逻辑、负面妥协与工程缓解防线。
