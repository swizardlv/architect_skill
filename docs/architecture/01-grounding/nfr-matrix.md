# 非功能需求（NFR）度量矩阵规范模板

## 1. 性能与容量双轨指标 (Performance & Scalability Dual-Track)

| 指标维度 | 目标基准 (Target Baseline) | 极限阈值 (Hard Boundary) | 度量方式 (Measurement Method) | 违约业务影响 (Blast Radius) |
|---|---|---|---|---|
| **核心 API 延迟 (P95)** | P95 < 200ms | P99 < 800ms | APM 分布式链路追踪探针 | 用户流失、客户端级联重试导致雪崩 |
| **系统稳态吞吐量** | 500 QPS (均值) | 2000 QPS (瞬时峰值) | 压力测试基准 (k6 / Locust) | 请求堆积排队、网关抛出 503 拒绝服务 |
| **推理首字延迟 (TTFT)** | P50 < 1.0s | P95 < 2.5s | 模型网关埋点与客户端握手计时 | 交互感知卡顿、用户中断等待 |
| **单任务认知步数上限** | 期望 <= 5 步 | 硬性限制 <= 8 步 | 编排引擎步数计数器 | 智能体迷航、长程死循环及预算耗尽 |
| **并发任务执行槽位** | 50 并发 | 100 并发 (排队限流) | 工作线程池与容器资源监控 | 内存溢出 (OOM)、宿主机调度抖动 |

## 2. 韧性、可用性与数据保真 (Resilience & Availability)

| 质量维度 | 指标定义 (SLO/SLA) | 防护保障策略 (Mitigation Tactics) | 验收与演练标准 (Validation Criterion) |
|---|---|---|---|
| **服务可用性** | 99.9% (每月计划外停机 < 43.8 分钟) | 多活实例部署、健康检查自动剔除异常节点 | 混沌注入探针主动拉偏节点演练 |
| **数据容灾指标 (RPO)** | RPO < 1 分钟 (数据丢失窗口 <= 60s) | 数据库 WAL 日志持久化秒级异步复制 | 灾备库切换与事务一致性核对 |
| **恢复时间指标 (RTO)** | RTO < 5 分钟 | 容器热重启、只读副本应急升主 | 自动化故障倒换测试脚本验证 |
| **一致性权衡模型** | 核心资金/状态强一致；辅助统计最终一致 | 事务 Outbox 机制 + 幂等事件对账流水 | 异步事件滞后超 3 秒告警触发 |
| **错误自愈与认知重试** | 单次失败后基于负向账本修正重试 <= 3 次 | 错误堆栈剪枝注入、阻断同类重试 | 连续 3 次失败硬回滚并通知人工审批 |

## 3. 经济学约束与资源上限 (Cost & Resource Bounds)

### 3.1 基础设施算力预算
- **单节点资源配额**：CPU <= 4 Cores，Memory <= 8GiB。
- **冷热数据分层生命周期**：热数据驻留数据库 30 天，温数据进入归档存储保留 180 天，到期自动压缩冷备。

### 3.2 Token 经济学与调用预算
- **单任务 Token 消耗硬上限**：单轮架构设计或推理执行不超过 8,000 Tokens。
- **Prompt 缓存命中目标**：系统级通用指令与 Schema 骨架缓存命中率 >= 70%。
- **成本熔断策略**：当单日累计消耗达到月度预算均摊的 120% 时，系统触发熔断告警并强制挂起非核心自适应探索任务。
